## About me

**Experience.** I've been a Software Engineer at **Celloscope** since January 2023, building enterprise web applications end to end: frontend, backend and database. My work spans internet banking, public university admissions and government office management. These are systems where correctness matters and traffic arrives in waves.

**What I'm exploring.** I'm digging into **distributed systems**: how services stay consistent, recover from failure and scale under load. The products I work on already run as microservices and face seasonal traffic spikes, so I want to understand the theory behind the patterns I use every day: replication, consensus, message queues and event-driven architecture.

**How I work.**
- **Configuration over code.** I build systems that adapt through settings, so one product can serve several clients without forks.
- **Data model first.** Clean schemas and predictable workflows make everything built on top of them simpler.
- **AI-assisted, test-verified.** I use AI coding agents to plan features, write code and generate tests. Every change is held to the same quality bar as hand-written code.
- **Code that outlives me.** I write and refactor so the next developer can pick it up without a guide.
