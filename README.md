## About me

**Experience.** I've been a Software Engineer at **Celloscope** since January 2023, building enterprise web applications end to end: frontend, backend and database. My work spans internet banking, public university admissions and government office management. These are systems where correctness matters and traffic arrives in waves.

**What I'm exploring.** I'm digging into **distributed systems**: how services stay consistent, recover from failure and scale under load. The products I work on already run as microservices and face seasonal traffic spikes, so I want to understand the theory behind the patterns I use every day: replication, consensus, message queues and event-driven architecture.

**How I work.**
- **Configuration over code.** I build systems that adapt through settings, so one product can serve several clients without forks.
- **Data model first.** Clean schemas and predictable workflows make everything built on top of them simpler.
- **AI-assisted, test-verified.** I use AI coding agents to plan features, write code and generate tests. Every change is held to the same quality bar as hand-written code.
- **Code that outlives me.** I write and refactor so the next developer can pick it up without a guide.

## Professional projects

- **Enterprise Internet Banking Platform** *(Jul 2025 – Present · Frontend)*: Internet banking for a large commercial bank, covering transfers, wallet payments, bills and self-service. I helped build a multi-bank admin portal with permission-based screens and config-driven reports, across 4 web portals serving 600,000+ users. `Angular` `Tailwind CSS`
- **Office Management System** *(Jan 2024 – Jun 2025 · Full Stack)*: An 11-module microservice platform for a government regulator. I built access control, employee records and HR workflows such as promotions, transfers and multi-step leave approvals. `Angular` `Node.js` `Express.js` `Oracle` `JasperReports`
- **Centralized University Admission Platform** *(2023 · Full Stack)*: One admission system shared by a group of public universities, covering application, payment, admit cards and results. It is built for high-concurrency admission seasons. I worked across the portals, APIs and database and designed the official PDF documents. `Angular` `Node.js` `Express.js` `PostgreSQL` `JasperReports`

## Personal projects

- **[History Of](https://history-of.nazmussakib.app)** *([source](https://gitlab.com/eng-nazmussakib/history-of-app))*: Type a country and see its whole history on one timeline, covering 191 countries and 5,000+ sourced events. Seed scripts collect events from Wikidata and Wikipedia, parse BCE and fuzzy dates such as "c. 1200", remove duplicates and keep a source link for every event. Search handles names, aliases and typos with PostgreSQL full-text search and pg_trgm and timeline pages are cached on Cloudflare. `Next.js` `React` `PostgreSQL` `Neon` `Cloudflare Workers`
